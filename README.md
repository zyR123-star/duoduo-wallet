# 多多钱包

个人使用的记账 PWA。可以保留为纯本机账本，也可以连接与佳嘉记账相同的 Supabase 项目，双方配对后只读查看对方允许的账单。

正式网址：https://zyr123-star.github.io/duoduo-wallet/

## 使用

双击 `start-wallet.cmd`，浏览器会打开 `http://127.0.0.1:4180/`。

在 Edge 或 Safari 中可以把页面安装到桌面或主屏幕。第一次联网打开后，Service Worker 会缓存页面，断网也能继续记账。

## 与佳嘉记账互连

- 共享服务已在 `config.js` 中预配置，两个应用默认连接同一个 Supabase 项目。
- 如果佳嘉记账已经执行过 `schema.sql`，多多钱包不需要重复执行。
- 多多钱包和佳嘉记账分别登录各自账号，然后用任意一方生成的 6 位配对码连接。
- 每条账单可选择“仅自己”或“对方可见”，默认仅自己。
- 对方只能查看共享账单，不能编辑、删除或更改权限。
- 私密账单由数据库行级权限拦截，不会进入对方设备。
- 明细页可在“双方 / 我的 / 对方”之间切换，也可以从配对信息直接打开对方共享账本。
- 每次打开记账弹层会生成固定账单 ID，连续点击和网络重试不会重复写入。

## 数据

- 完整备份：设置页导出 JSON。
- 表格导出：设置页导出 CSV。
- 恢复：设置页选择 JSON；恢复前会确认，并用备份替换当前账单。
- 未登录共享账本时，数据只存在当前浏览器。
- 连接 Supabase 后，云端模式下会缓存当前账号有权查看的账单。

## 注册说明

- 不需要 GitHub 账号，普通用户使用邮箱和密码注册。
- 当前已关闭强制邮箱验证，注册成功后会直接登录，不再等待确认邮件。
- 邮箱必须能正常收信，不要填写昵称、手机号或保留测试域名。

## 文件

- `index.html`：页面结构与图标。
- `styles.css`：浅色、深色和移动端布局。
- `app.js`：记账、统计、筛选、备份与导入。
- `cloud.js`：Supabase 登录、配对和共享账单接口。
- `supabase/schema.sql`：共享账本表结构、配对函数和行级权限。
- `sw.js`：离线缓存。
- `tools/server.cjs`：本地静态服务。
