# 多多钱包

个人使用的本地记账 PWA。收入、支出、分类、账户和备注都保存在浏览器 IndexedDB，不接入银行，不上传账单。

## 使用

双击 `start-wallet.cmd`，浏览器会打开 `http://127.0.0.1:4180/`。

在 Edge 或 Safari 中可以把页面安装到桌面或主屏幕。第一次联网打开后，Service Worker 会缓存页面，断网也能继续记账。

## 数据

- 完整备份：设置页导出 JSON。
- 表格导出：设置页导出 CSV。
- 恢复：设置页选择 JSON；恢复前会确认，并用备份替换当前账单。
- 数据只存在当前浏览器。清理浏览器网站数据会同时清空账本，定期导出备份。

## 文件

- `index.html`：页面结构与图标。
- `styles.css`：浅色、深色和移动端布局。
- `app.js`：记账、统计、筛选、备份与导入。
- `sw.js`：离线缓存。
- `tools/server.cjs`：本地静态服务。
